# Tic Tac Toe Game
This is the Tic Tac Toe project from the Odin Project. This project allowed me to practice the following concepts:

- Factory Functions
- Immediate Invoke Function Expressions (IIFEs)
- The Module Pattern
- Code Encapsulation
- Global & Local (block) Scope
- Closures
